# Analysis code: Estimating spreading-activation breadth and verification ability from remote associates responses

This repository contains the analysis code, simulation design, seeds, and summary results for the article
*Estimating spreading-activation breadth and verification ability from remote associates responses: A
generation–verification model* (manuscript in preparation). The model itself is available as the R package **gvmodel**
(https://github.com/gxnuyuanbo-hash/gvmodel).

Folder names follow the working directories of the project (in Chinese); their content is described below. Data,
networks, fitted models, and raw simulation output are not included (see *Data*); every script regenerates its
inputs from the sources listed there. Model names in the code use the letters of the development stage:
**A** = additive, **B** = multiplicative, **C** = shared-verification, **D** = generation–verification model; in the
code, verification ability is written `d` (in the article, *v*).

Seeds are generated by NumPy's `SeedSequence` from (study, condition, replication), so each simulated data set can be
regenerated on its own. The full simulation (6,200 data sets) took about six days on a laptop with two parallel fits.

## Software

Python 3 (NumPy, SciPy, pandas), R 4.4 with cmdstanr (CmdStan 2.40), posterior, loo, data.table, ggplot2, patchwork.
Run Python scripts with `python3 -I` from the folder that contains them; R scripts are run with `Rscript` from their
folder unless the header says otherwise.
